# Academics Student Management System
Academics is a comprehensive student management system built with PHP designed for educational institutions to manage students teachers courses tasks events and reports. The system features a premium dark-mode UI with role-based access control and clean authentication flow.

"- Secure Login System - Email/password authentication with CSRF protection"
"- Role-Based Access Control (RBAC) - Three-tier role system:"
"- Admin - Full access to all features including user management, activity logs, settings"
"- Staff - Access to students, courses, tasks, events, reports, emergency alerts"
"- Student - Limited access to own profile and reports"
"- Session Management - startSecureSession() with secure cookie handling"
"- Auth Ordering Fix - requireAuth()/requireStaff()/requireAdmin() now called before header.php includes, fixing the critical headers already sent error"

"- Admin Tools - Manage users, view activity logs, emergency alerts, settings"
"- Teacher Management - View and manage teacher accounts (staff role)"
"- Student Profiles - Student information with associated user accounts"
